# ATM Management System

## About the Project
This is a simple ATM Management System built using Python. It simulates basic ATM operations through a menu-driven program.

## Features
- Create a PIN
- Change PIN
- Check bank balance
- Withdraw money
- Menu-driven interface

## Technologies Used
- Python

## How to Run
1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python atm.py
```
